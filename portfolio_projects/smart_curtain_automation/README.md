# Smart Curtain Automation Prototype

Academic embedded automation prototype for motor-driven curtain open/close control.

## Features

- Open/close switching logic
- Stepper motor control after servo torque limitations
- Direction-based movement
- Limit-switch-ready control structure
- Serial commands for testing

## Files

- `stepper_curtain_controller.ino` - Arduino reference sketch for stepper-driven curtain movement.

## Status

Reconstructed portfolio demo based on the completed academic prototype.
