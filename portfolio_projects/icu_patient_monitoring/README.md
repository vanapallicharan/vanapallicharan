# ICU Patient Monitoring System

Innovation/research proposal for centralized ICU vital monitoring and emergency visibility.

## Proposed Workflow

Patient sensors -> control gateway -> dashboard -> doctor monitoring -> alert logic -> action support

## Vitals Covered

- Heart rate
- Blood pressure
- Pulse rate
- Respiration / air intake
- SpO2
- ECG status
- Temperature
- Motion indicator
- Emergency alerting

## Files

- `dashboard_simulation.py` - command-line simulation of vitals ingestion and alert rules.

## Status

Proposal completed. The included simulator is a portfolio demo for the alerting/dashboard logic.
