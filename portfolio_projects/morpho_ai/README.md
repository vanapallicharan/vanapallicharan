# Morpho AI

Morpho is a personal R&D project for a local AI assistant that can remember context, adapt to user preferences, and support research and workflow automation.

## Goals

- Run locally where possible using local LLM workflows.
- Store useful memory and conversation context.
- Provide task routing, suggestions, screen/context awareness, and assistant behavior planning.
- Grow into an automation-oriented assistant that can support research and daily workflows.

## Current Source

The active Morpho source code lives at the repository root and includes modules for:

- AI adapter and chat handling
- Conversation memory
- Distillation and vector storage
- Activity monitoring
- Suggestion and automation engines
- Dashboard UI
- Permission and action routing
