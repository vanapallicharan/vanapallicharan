# Smart Magnetic Door Lock Prototype

Academic IoT access-control prototype using RFID, ESP32, relay control, and cloud/dashboard concepts.

## Features

- RFID-based unlock
- Remote unlock command concept
- Time-window access rules
- Relay-driven solenoid/magnetic lock actuation
- Push-button override
- Serial diagnostics for testing

## Files

- `esp32_rfid_lock.ino` - ESP32/Arduino-style reference sketch.

## Status

Reconstructed portfolio demo based on the completed academic prototype.
